# 용어집 · 말투 결정 (authoritative)

상태: `proposed`(초안·승인 대기) · `approved` · `conflict`. 적용 범위: 잭 1편 (OpenGOAL, ntsc_v1) 전체, 별도 표기 없으면 모든 장면.
**원칙 (G-000, 참고)**: 음성은 영어 원본 그대로이므로, 귀에 들리는 고유명사·용어는 원음에 가깝게 음차하고,
의미가 핵심인 일반 명사(지명의 설명 부분 등)는 번역한다.

근거 등급: **SCEK** = 2002–2012 SCEK 발매·홍보 자료(2차 출처) · **namu** = 나무위키 관용 표기 · **신규** = 근거 없음, 이번 프로젝트 제안.
1편 한국어판 인게임 원문은 존재하지 않으며, 2·3편 한국어판 원문도 확인하지 못함 (추출하려면 한국판 잭2/잭3 ISO 필요).

## 자막 줄 규칙 (L-xxx, 기술·표기)

- L-000: 자막은 2줄 이내 (사용자 승인). 게임 화면에서 검증.
- L-000a: 사모스의 설명 대사가 길어지지 않게 끊고, 한국어는 영어 음성의 실제 발화 시간에 맞춘다 (사용자 지시, 2026-10-15).
- L-001: 자막 한 줄 = 원문 한 줄(같은 타이밍). 한 문장이 여러 줄에 걸치면 **같은 화자의 연속 줄 안에서** 의미를 재배치해도 됨 (어순 차이). 줄 수는 바꾸지 않음.
- L-002: 1편 폰트에 영문 소문자·`…`·따옴표 일부가 없음 → 영문은 대문자, 말줄임표는 `...` (검사기가 강제).
- L-003: `~D` 등 포맷 토큰은 개수·순서 보존, `<PAD_X>` 류는 위치 이동 가능·보존 (검사기가 강제).
- L-004: 화자 `???` 는 정체를 숨기는 연출이므로 그대로 `???`.
